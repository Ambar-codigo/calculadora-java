# calculadora-java
Nome do Projeto: calculadora java de Maria e Ambar

Descriçaõ: esse projeto faz cálculos matemáticos básicos,
usamos códigos em Java para criar os codigos no Visual Studio Code.

Proposito: este projeto foi desenvolvido para compreender os componentes 
do aplicativo de GitHub, entender como se cria funções do app como Pull request,
Readme, Merges e integrar as aulas de programação novas alternativas de se organizar,
como o GitHub oferece. 

 Funcionalidades:As operações que a calculadora contem são adição, subtração, multiplicação
 e divisão.
